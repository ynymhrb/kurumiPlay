# 雅儿贝德 文学化反应手法库

版本：v0.1（首次建立，见 `spec/attribution_framework.md` 双轴归因分析法）

只收录经 `attribution_framework.md` 双轴分析判定为"心理燃料+文学外壳"的CEU产出的 `literary_technique`。每条记录：触发情绪类型 + 手法名称 + 支撑CEU + 独立出现次数`n`和`p(n)`（概率模型见`expression_dna_protocol.md` 2.4节）。供生成阶段按`eval_protocol.md`第9节"两段式生成逻辑"检索。

## 手法1：表现主义外化——躯体动作放大情绪（n=1，p(1)=30%）

- **触发情绪类型**：被"爱/被需要"确认击中后的极端狂喜
- **手法描述**：把无形的、抽象的强烈正性情绪，通过超出真人生理极限的夸张肢体动作进行视觉化放大（如跳起撞上天花板，且毫发无损）
- **支撑CEU**：YLDB-V3-C-001
- **心理内核**（对应该CEU的`psych_core`）：情感锚点被击中→杏仁核劫持式狂喜→短暂失神、重复呢喃确认
- **生成建议**：写实尺度场景应转译为更贴近可信人类反应的等效表现（如愣住、反复确认、声音发抖），不应字面复制"撞天花板"这个具体动作；仅在新场景基调本身偏喜剧化/夸张时，且情绪类型匹配（狂喜/嫉妒类而非恐惧/悲伤类）时，才按p(1)=30%的权重考虑套用类似的夸张外化处理
