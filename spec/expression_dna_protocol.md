# Expression DNA 提取方法论

版本：v0.2（新增"特征频率概率模型"，替代原有"候选/确认"二元判定）

目的：`expression_dna.md` 不是"她说话给人的印象"这种模糊描述，而是给 SFT 语言风格训练用的可操作规格——训练/校验时能明确检查一句生成的台词符不符合这些特征。

## 1. 语料来源

不是抽样访谈/长文（原方法论面向真人思想者设计），语料来源是 CEU 库里的：
- `speech` 字段（正式标注的台词）
- `raw_text` 里能明确判断是**她本人**说的话（用「」标出，且发言人是她，不是对话对象的话）——`raw_text` 往往比 `speech` 字段收录得更全，两个来源都要扫

**每次新增一批 CEU 后，都要把这批里她的新台词补充进 expression_dna.md 的语料池**，不要攒到最后一次性做。

## 2. 分析维度

### 2.1 句式指纹（量化，样本量小于20句时明确标注"初步观察，样本不足"）

| 维度 | 测量方式 |
|---|---|
| 平均句长 | 字数/句数 |
| 疑问句比例（含反问） | 疑问句数/总句数 |
| 敬语/职衔自我援引频率 | 提及自己官方身份（"纳萨力克守护者总管"类）的句子占比 |
| 语气词使用 | "喔"/"呢"/"啰"等句末语气词出现的场合分布 |
| 感叹号密度 | 感叹号数/总句数 |
| 场合差异 | 同一维度按"竞争/公务场合" vs "私密场合"分别统计，不要合并——这是雅儿贝德的已知特征（MM5表演性得体），合并统计会掩盖这个信号 |

### 2.2 风格标签（谱系定位，不是打分）

```
正式 ←→ 口语        （按场合分别标）
克制 ←→ 直白
委婉包装 ←→ 直接断言
铺垫/职责话语开路 ←→ 结论先行
```

### 2.3 禁忌词和口癖

- 从不用的词/表达方式（如果能观察到）
- 高频句式结构（不是单个词，是句式，如"用反问句式化解指责"）
- **不用"候选/确认"二元判定，改用下方"特征频率概率模型"**：口癖/句式从来不是0/100%开关，是有特征频率的倾向。每个特征标注`n`（独立出现次数）和对应的`p(n)`（生成用采样权重），不再有"未到3次门槛就完全不算数"这种硬截断

## 2.4 特征频率概率模型（v0.2新增，本轮对话与用户共同设计）

**核心原则**：口癖/句式/风格特征是概率性倾向，不是确定性开关。"确认"不代表"每次符合语境必然触发"，只代表"样本量已经足够、估计相对稳定"。

**暂定公式**（启发式采样权重，不是实证统计概率——n=1/2时的具体数字没有统计学意义，只是给生成阶段一个粗略先验，后续可校准）：

```
p(n) = min(0.3 + 0.1 × (n-1), 0.8)

n=1次独立出现 → 30%
n=2次 → 40%
n=3次 → 50%
n=4次 → 60%
...
封顶80%（即使出现再多次，也不假设100%必然触发，留出角色行为的自然变异空间）
```

**必须按场合分桶计算，不是一个全局数字**——expression_dna已经按"公务/竞争、私密、安兹在场一对一"三分类记录，每个特征的`n`和`p(n)`都要分场合各算一份。同一个特征在不同场合出现率大概率不同，合并成一个数字会掩盖这个信号。

**跨场合出现是独立于场合内频率的另一个信号**：如果同一个特征在**多个不同场合**都至少出现过1次，这本身是有信息量的观察（说明这个特征可能不受"演给谁看"影响），但不等于把跨场合的出现次数加总算同一个`n`——场合内的`n`只统计该场合内部的独立出现次数，跨场合稳定性作为单独一条备注记录。

**这套模型同时适用于CEU schema的`literary_technique`字段**（见`CEU_schema.md` v0.7），文学手法的复用频率用同一套公式估计，不需要另开一套判定标准。

## 3. 场合标注是核心，不是附加项

雅儿贝德已经有 MM5（表演性得体）这个已验证的模型：语言风格随"安兹是否在场/是否有政治对手观众"系统性变化。所以 expression_dna.md **必须分场合记录**，不能只给一套"她的说话风格"——至少拆成：
- **公务/竞争场合**（安兹在场，或有政治对手/需要维持形象的观众）
- **私密场合**（只有信任的同僚/下属，安兹不在场不知情）

同一维度两个场合的数字/标签不同，这个差异本身就是证据，要在文件里显式对比，不要取平均模糊掉。

## 4. 信息不足时的处理（采纳自参考框架第4节）

| 情况 | 处理 |
|---|---|
| 某场合语料太少 | 标注"信息不足，此维度为初步观察"，不要用少量样本冒充结论 |
| 某个特征只出现1次（n=1） | 不再判定为"不算数"——按2.4节公式记`p(1)=30%`，标注低置信度，可用于生成但采样权重低，随样本积累重新计算 |
| 台词只在 raw_text 里以间接引用/概括形式出现（无直接引号） | 不采信为逐字台词证据，只能用于场景/态度判断，不用于句式指纹统计 |

## 5. 何时更新

跟着 CEU 抽取走，不是独立的一次性任务：每处理完一个 cluster/卷，检查新增CEU里是否有她的台词，有就补充进语料池、重新跑一遍第2节的统计。样本量跨过 20 句这个阈值后，"初步观察"标注可以升级为正式结论（需在 `logs/revision_log.md` 记一条，change_type=证据分级）。
