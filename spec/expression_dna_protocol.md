# Expression DNA 提取方法论（言语风格指纹的构建方法）

版本：v0.3（架构迁移：产出目标从独立的`expression_dna.md`文件改为`profile.yaml`的`speech_register`字段，方法论内容不变；概率模型主副本迁移到`character_static_profile_schema.md`，本文件引用不重复）

目的：`speech_register`不是"她说话给人的印象"这种模糊描述，而是给 SFT 语言风格训练用的可操作规格——训练/校验时能明确检查一句生成的台词符不符合这些特征。

## 1. 语料来源

不是抽样访谈/长文（原方法论面向真人思想者设计），语料来源是 `events/<卷>.yaml` 里的：
- `speech_content` 字段（正式标注的台词）
- `raw_quote` 里能明确判断是**她本人**说的话（用「」标出，且发言人是她，不是对话对象的话）——`raw_quote` 往往比 `speech_content` 字段收录得更全，两个来源都要扫

**每次新增一批事件后，都要把这批里她的新台词补充进`profile.yaml`的`speech_register`语料池**，不要攒到最后一次性做。

## 2. 分析维度

### 2.1 句式指纹（量化，样本量小于20句时明确标注"初步观察，样本不足"）

| 维度 | 测量方式 |
|---|---|
| 平均句长 | 字数/句数 |
| 疑问句比例（含反问） | 疑问句数/总句数 |
| 敬语/职衔自我援引频率 | 提及自己官方身份（"纳萨力克守护者总管"类）的句子占比 |
| 语气词使用 | "喔"/"呢"/"啰"等句末语气词出现的场合分布 |
| 感叹号密度 | 感叹号数/总句数 |
| 场合差异 | 同一维度按"竞争/公务场合" vs "私密场合"分别统计，不要合并——这是雅儿贝德的已知特征（MM5表演性得体），合并统计会掩盖这个信号 |

### 2.2 风格标签（谱系定位，不是打分）

```
正式 ←→ 口语        （按场合分别标）
克制 ←→ 直白
委婉包装 ←→ 直接断言
铺垫/职责话语开路 ←→ 结论先行
```

### 2.3 禁忌词和口癖

- 从不用的词/表达方式（如果能观察到）
- 高频句式结构（不是单个词，是句式，如"用反问句式化解指责"）
- **不用"候选/确认"二元判定，改用"特征频率概率模型"**（公式定义见`character_static_profile_schema.md`，不在此重复）：口癖/句式从来不是0/100%开关，是有特征频率的倾向。每个特征标注`n`（独立出现次数）和对应的`p(n)`（生成用采样权重），不再有"未到3次门槛就完全不算数"这种硬截断。**这套模型同时适用于文学手法（`literary_techniques.md`）的复用频率估计**，不需要另开一套判定标准

## 3. 场合标注是核心，不是附加项

语言风格随"安兹是否在场/是否有政治对手观众"系统性变化（对应`psychological_structure`里已确认的表演性模式）。所以`speech_register`**必须分场合记录**，不能只给一套"她的说话风格"——至少拆成：
- **公务/竞争场合**（安兹在场，或有政治对手/需要维持形象的观众）
- **私密场合**（只有信任的同僚/下属，安兹不在场不知情）

同一维度两个场合的数字/标签不同，这个差异本身就是证据，要在文件里显式对比，不要取平均模糊掉。

## 4. 信息不足时的处理（采纳自参考框架第4节）

| 情况 | 处理 |
|---|---|
| 某场合语料太少 | 标注"信息不足，此维度为初步观察"，不要用少量样本冒充结论 |
| 某个特征只出现1次（n=1） | 不再判定为"不算数"——按2.4节公式记`p(1)=30%`，标注低置信度，可用于生成但采样权重低，随样本积累重新计算 |
| 台词只在 raw_quote 里以间接引用/概括形式出现（无直接引号） | 不采信为逐字台词证据，只能用于场景/态度判断，不用于句式指纹统计 |

## 5. 何时更新

跟着事件提取走，不是独立的一次性任务：每处理完一卷，检查新增事件里是否有她的台词，有就补充进语料池、重新跑一遍第2节的统计。样本量跨过 20 句这个阈值后，"初步观察"标注可以升级为正式结论（需在 `logs/revision_log.md` 记一条，change_type=证据分级）。
