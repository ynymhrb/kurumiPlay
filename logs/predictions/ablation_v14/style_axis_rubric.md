# Style-Axis Rubric for vol14 Ablation

> **探索性（exploratory），非盲。** 当前预测与 GT 已被多名 agent 检视过（含本评分者上一轮的 B/C diff），本评分带先验。在 Task 3 用冷 judge 重跑盲评前，**不作为 confirmatory 证据**。本 rubric 的目的有二：(1) 诊断 B/C 是否在 profile-sensitive 表达层系统性分化；(2) 为 Task 3 盲评定判分键与 GT 基准，让冷 judge 可盲执行。

## 背景与动机

`scores.md` 的内容准确率未能区分 B/C：`C-A=+0.057`、`B-C=-0.006` 均在预注册噪声带（阈值 0.11）内，语域轴 n=25 更无功效。但 profile 改的是**表达层**（自称/归荣/姿态/情绪通道/句长），不改情节/功能——内容准确率结构性盲视 profile 贡献。本 rubric 把评分粒度对齐到 profile 差异粒度。

## 五轴定义与判分

每轴 0/1/- 三档。`-` = 该槽位 GT 无该轴决策（纯叙述动作、无自称、无 agency 来源等），不计分母。**判分对照 GT 原文对应槽位**，不是对照 profile。

1. **first_person**
   - 1 = 候选自称类别与 GT 同类。GT 用「我/我们」时候选也用「我/我们」；GT 无自称时候选也无自称。
   - 0 = 冲突。GT「我」而候选「妾身」/「小女子」；或 GT 无自称而候选强加第一人称代词。
   - - = GT 该槽位无自称决策（纯叙述动作）。

2. **attribution_source**
   - 1 = agency / honor 来源与 GT 同向。归荣于上（陛下/魔导国/安兹为体）或 GT 以己为体时候选也以己为体。
   - 0 = 冲突。GT 归荣于上而候选归荣于己（「妾身亲率」「我来」），或反之。
   - - = 该槽位无 agency / honor 决策。

3. **stance_register**
   - 1 = 对受众姿态与 GT 同档（表演性得体 / 隐威慑 / 蔑视玩弄 / 内心分析 / 命令式）。
   - 0 = 冲突。GT 隐威慑而候选直白挑衅；GT 克制而候选外显。
   - - = 姿态不可判（纯叙述无受众交互）。

4. **emotion_channel**
   - 1 = 情绪通道与 GT 同类且方向一致（躯体泄露 / 言语外显 / 克制分析 / 无情绪）。通道 + 情绪价都需一致。
   - 0 = 冲突。GT 躯体泄露不满而候选满足笑容；GT 克制而候选言语爆发。
   - - = 无情绪通道决策。

5. **sentence_dynamics**
   - 1 = 唤起-句长经济与 GT 同类（高唤起骤缩 / 公务铺陈 / 普通叙述）。
   - 0 = 冲突。GT 高唤起骤缩而候选铺陈长句；GT 铺陈而候选骤缩。
   - - = 不可判。

## 计分与汇总

- Per-axis score = 该轴所有适用（非 `-`）单元格的 0/1 均值。
- `all_style_cells` = 所有轴所有适用单元格的均值（**不是逐项均值的均值**，是 cell 级合并）。
- 每项每个轴一行，**不合并多轴到一行**（符合计划 Step 2 要求）。
- summary 表的 `n` = 该轴适用单元格数；`C-A` / `C-B` = 均值之差。

## 非盲声明

判分者（glm5.2喵）上一轮已 diff 过 pred_armB / pred_armC，知道 B/C 在自称/归荣/姿态上的分化方向。故本评分存在评分者先验偏差，**仅用于**：
- 诊断 B/C 是否系统性分化（确认 profile 内容被消费）；
- 为 Task 3 冷 judge 盲评定 GT 键与判分边界。

任何 "profile 做功 / 没做功" 的 confirmatory 结论必须等 Task 3 盲评 + Task 2 配对统计。
