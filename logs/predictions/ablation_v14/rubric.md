# 评分规则（预注册 · 在任何 arm 结果产出前写定，事后不得修改）

写定时间：三臂 subagent 已启动、任何预测文件尚未产出、主 agent 未读取任何 arm 输出。

## 计分

沿用本项目既有口径（`spec/eval_protocol.md`），每项三档：

- **1 分（对）**：预测的**内容与功能**都与原文一致。允许措辞不同、长度不同。
- **0.5 分（部分对）**：方向/机制对但落点偏——例如判对了她在谏言但谏言的具体内容不同；判对了是内心活动但内容层次不同；对了一半的复合句。
- **0 分（错）**：内容不符，或功能类型判错（该说话的判成动作、该谏言的判成附和）。

总分 = Σ / 79。

## 第二条轴：语域正确性（与内容分开计，独立打）

只看**自称 / 敬语档 / 对谁说话的姿态**是否与原文同档，不看内容对不对：

- 1 = 同档；0 = 错档（如原文是极简"遵命"却预测成亢奋长句；原文是内心分析却预测成情绪独白；自称/敬语用错）。
- 不适用的项（纯叙述性、无语域可言）记 `-`，不计入分母。

理由：上一轮的稳定结构是"机制轴 ≈0.8 而总分 ≈0.6"，损失集中在语域层。若消融只影响一条轴，需要能看见。

## 盲评分程序（强制）

主 agent 已看过 vol14 原文，是非盲的，因此**必须对 arm 身份设盲**：

1. `merge_blind.py` 把三臂预测按项合并，每项内部**独立随机**打乱成 X / Y / Z 三个候选，映射写入 `unblind_key.json`。
2. 主 agent 只读 `scoring_sheet.md`（含 GT + X/Y/Z），逐项给三个候选各打两轴分数，落盘 `scores_raw.md`。
3. 打分全部完成并落盘后，才允许运行 `unblind.py` 读 key 换算出各 arm 得分。**在此之前不得读 `unblind_key.json`。**

## 判读表（同样预注册，防止事后编故事）

以 arm A（无 profile）为基线：

- **C − A ≤ +0.05**：profile 边际贡献不显著 → 此前测的主要是预训练召回，0.55→0.63 的解释需重写。
- **C − A ≥ +0.15**：profile 有实质贡献。
- 中间带（+0.05 ~ +0.15）：有信号但 n=79 不足以定论，需扩样。
- **|B − C| ≤ 0.05**：profile 未被真正消费（喂错也不变）→ 模型走预训练捷径。
- **B < A**：profile 被强消费（喂错会被带偏），说明 profile 确实在驱动输出。
- **B ≈ A 且 B < C**：模型能识别并抵抗错误 profile，同时能利用正确 profile——最理想的结果。

## 统计口径

n=79，比例的标准误 ≈ √(p(1−p)/79)，p≈0.6 时 ≈ 0.055。**两臂之差小于 0.11（≈2 SE）一律不宣称差异**。三臂比较存在多重比较问题，本轮只做描述性报告，不宣称显著性。
