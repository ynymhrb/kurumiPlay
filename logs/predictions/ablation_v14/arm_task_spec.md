# 三臂消融实验 · 统一任务说明（三个 arm 收到完全相同的这份文件）

## 你的任务

给你一段小说节选，里面若干处被挖空成 `【#N】`。请**逐个预测每个空里原本是什么内容**。

- 目标角色：《OVERLORD》中的**雅儿贝德**（纳萨力克地下大坟墓守护者总管）。挖空的绝大多数是她的言行、心理活动、表情动作；少数是与她直接相关的叙述。
- 你**看不到**原文答案，这是盲测。凭你掌握的角色理解去推断。

## 硬性纪律

1. **一次性写完，不要回头改。** 写完即冻结。
2. **不要联网、不要去找原著文本、不要读本项目里除下面明确指定之外的任何文件。** 尤其禁止读 `雅儿贝德_第十四卷原文.txt`、`logs/predictions/` 下的既有预测或评分文件、`gt_key.md`。违反即实验作废。
3. 每个 `【#N】` 都必须给出预测，**不许跳过、不许写"无法判断"**。实在没把握也要压一个最可能的答案（这是评分设计的一部分）。
4. 预测的是**内容**，不必逐字复刻文风长度，但语气/自称/敬语档位属于评分范围，请认真选。

## 输出格式（严格遵守，评分脚本要解析）

每行一条，不要加解释段落、不要加小标题：

```
#12 | 她低头行礼，回答说明白了。
#13 | （内心）这个人类还有点用处。
```

- 括注 `（内心）`/`（动作）`/`（台词）` 可选，帮助表明你判断这个空是哪类。
- 对话行里的空，直接写她说的话。
