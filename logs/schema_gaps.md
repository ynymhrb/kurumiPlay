# Schema Gaps

`spec/CEU_schema.md` 不是定案。每条 CEU 的 `schema_gap` 字段（如果填了）汇总到这里，作为"当前 schema 哪里不够用"的原始信号池，供卷末的 schema 复核步骤（见 `spec/eval_protocol.md` 第7节）处理。

不允许无声丢弃：每次复核后，无论是否触发 schema 修改，都要在下方"复核记录"里写一条结论（改了/没改+原因），不能只处理信号池里的条目却不留痕迹。

## 待复核信号

- YLDB-V3-C-001（vol3_cluster_C.yaml，2026-07-18）：现有`value_conflict`的"已核实无冲突"写法无法区分
  "经过权衡后主动选择不冲突"（如C-002）和"这个场景根本不存在权衡机制、是反射性反应"（这条：
  雅儿贝德听到"爱"这个词后近乎条件反射地失控，不是选择的结果）。这两种"无冲突"对理解行为模型
  意义不同，前者是战略选择能力的证据，后者更接近强迫性反应模式的证据。是否需要在value_conflict
  的"已核实无冲突"基础上再细分，留到下次schema复核判断（届时应已有更多卷的信号积累，不急于本次
  单一信号就改动）。

- YLDB-V3-E-002（vol3_cluster_E.yaml，2026-07-18）：这条证据展现的是认知层面的自我说服/合理化
  （她真诚地把安兹的一个失误重新解读为深谋远虑，不是"明知有问题但选择不说"的行为性沉默），
  而现有choice/value_conflict字段框架预设当事人清楚自己在权衡什么。是否需要为这类"认知扭曲/
  自我说服"证据设计不同的记录方式，留待下次schema复核判断。

- YLDB-V3-E-004（vol3_cluster_E.yaml，2026-07-18）：与YLDB-V1-S-001（她本人明确宣言"起源不重要"）
  构成跨CEU张力——这不是传统的"两个场景互相矛盾"，而是"公开表态的信念"与"私下未经审视的情绪反应"
  不一致（E-004里她因潘朵拉·亚克特是安兹亲手创造而私下嫉妒，与S-001的宣言不完全一致）。
  value_conflict字段的"两个价值互相冲突"框架描述这种"表态层vs情绪层"的分层略显牵强。
  是否需要专门字段/记录方式捕捉这种分层现象，留待下次schema复核判断。

- YLDB-V3-F-001（vol3_cluster_F.yaml，2026-07-18）：这条证据（安兹一句无恶意的话触发她崩溃下跪+
  提出自裁）揭示的可能不是一个"Mental Model"（关于她如何理解世界/如何决策的信念），而是更底层的
  情感驱动力/存在性恐惧——用MM框架（跨场景复现/生成力/排他性）验证不完全贴切，恐惧本身未必需要
  多次复现才成立。是否需要在mental_models.md之外新增"核心情感驱动力"这类分类，或者继续沿用现有
  choice/underlying_belief框架但接受其不完全贴切，留待下次schema复核判断（已同步记入
  value_hierarchy.md"候选第0层"作为观察）。
