# Schema Gaps

`spec/CEU_schema.md` 不是定案。每条 CEU 的 `schema_gap` 字段（如果填了）汇总到这里，作为"当前 schema 哪里不够用"的原始信号池，供卷末的 schema 复核步骤（见 `spec/eval_protocol.md` 第7节）处理。
